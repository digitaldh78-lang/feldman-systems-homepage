# Feldman Systems — דף הבית

עמוד נחיתה לפלדמן מערכות — בקרת בית חכם מבוססת Home Assistant.

**מיצוב:** מחשב הבקרה הוא המוצר. תאורה, אקלים, תריסים, אבטחה ומולטימדיה מתחברים אליו למערכת אחת שפועלת מקומית בנכס.

## קבצים

| קובץ | תוכן |
|---|---|
| `index.html` | מבנה העמוד, RTL, 11 סקשנים |
| `style.css` | מערכת עיצוב מלאה — טוקנים, קומפוננטות, רספונסיביות |
| `app.js` | אינטראקציות — Vanilla JS, בלי תלויות |

הפעלה: פתיחת `index.html` בדפדפן. אין שלב build.

## מערכת עיצוב

```css
--bg:        #F4F7FA   /* רקע ראשי */
--surface:   #FFFFFF   /* כרטיסים ומשטחים */
--primary:   #0A1128   /* כותרות H1–H3, סקשנים כהים */
--primary-2: #0F172A   /* H4–H6, כרטיס כהה פנימי */
--text:      #334155   /* טקסט גוף */
--accent:    #00D2FF   /* Accent ראשי — כפתורים, אייקונים */
--accent-2:  #00A896   /* Accent משני — eyebrow, סטטוסים */
--border:    #E2E8F0   /* גבולות והפרדות */
```

**חוקים:** אין `#000000`. אין אדום/כתום/צהוב. כל הצללים והשקיפויות נגזרים מ-`--primary` או מה-Accent בלבד — אין גוונים חדשים.

**טיפוגרפיה:** Heebo לכותרות · Assistant לטקסט גוף.

## סקשנים

1. **Hero** — מחשב הבקרה + חמישה nodes מרחפים שמסמלים מערכות מתחברות
2. **אקוסיסטם** — תאימות לפלטפורמות (Home Assistant, Google Home, Alexa, HomeKit, Zigbee, MQTT, Matter, Tuya)
3. **הליבה** — מחשב הבקרה, Home Assistant, בקרים, רשת, סצנות
4. **פתרונות** — גלריה מתרחבת, 6 תחומים
5. **למי זה מיועד** — דירות · וילות · קבלנים ואדריכלים
6. **שלב התכנון** — פנייה לקבלנים ואדריכלים
7. **הוכחה** — מערכת ניטור האקווריומים על Home Assistant
8. **מאחורי הקיר** — תשתית והתקנה
9. **המייסד** — קובי ניסן פלדמן
10. **התהליך** — 7 שלבים
11. **שאלות נפוצות** + **CTA** + פוטר

## אינטראקציות

Scroll reveal מדורג עם blur · parallax ב-Hero · גלריה מתרחבת (hover בדסקטופ, לחיצה במובייל) · ספירת מספרים · ציר תהליך שנצבע בגלילה · כפתורים מגנטיים · tilt תלת-ממדי · אקורדיון · progress bar · ניווט דביק עם קישור פעיל.

`prefers-reduced-motion` מכובד — כל האנימציות נכבות.

## נגישות

Skip link · `aria-expanded` על אקורדיון, תפריט וגלריה · Escape סוגר תפריט · מטרות מגע ≥52px · טבעת פוקוס `#00D2FF`.

## פתוח לטיפול

- QA ויזואלי מלא טרם בוצע בדפדפן
- לוגואים של Google Home / Alexa / HomeKit הם אייקונים גנריים, לא הלוגואים הרשמיים
- אנימציית "When / And / Then" לאוטומציות — טרם נבנתה
- התמונות נטענות מספריית המדיה של אתר ה-staging; להחלפה לנתיבים מקומיים לפני production
